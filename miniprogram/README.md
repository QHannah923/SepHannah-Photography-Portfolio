# SepHannah Studio 微信小程序开发版

更新时间：2026-09-22。已有六个页面和生产网站接口连接；尚未完成微信开发者工具编译、真机验证或平台审核，不能作为已发布小程序交付客户。

## 页面与流程

- 工作室：真实作品、四类拍摄、套餐起价、数码 + 胶片说明与预约步骤。
- 选风格：清透感 / 胶片感 / 网感 / 电影感，叠加婚纱、毕业、领证、写真场景筛选。可收藏六张参考，点击图片查看大图。
- 档期预约：套餐价格、真实胶片选项、参考照片、Brisbane 月历与时段、联系方式、偏好日期、询单提交及私人查询码。
- 我的询单：报价、确认拍摄、修片和完成状态；支持下拉刷新及换手机后通过查询码找回。
- 拍摄须知：交付、定金、改期、妆造、路费及真实胶片等常见问题。
- 询单隐私说明：收集的资料、网站/数据库/发信服务、本机记录与联系删除方式。

照片收藏只保存在本机；提交后参考照片链接会随拍摄想法进入网站后台和通知邮件。没有独立的小程序数据库，使用现有网站 `/admin` 管理同一份订单。

## 导入开发工具

1. 在微信公众平台注册“小程序”，按照自己的真实主体情况完成所需信息与验证。不要把服务号/订阅号 AppID 当成小程序 AppID。
2. 安装官方微信开发者工具，使用管理员微信扫码登录。
3. 导入本目录，填入真实 AppID。当前 `project.config.json` 中 `touristappid` 仅是占位符。
4. 将本目录 `project.config.json` 的 `appid` 改为真实值。AppID 本身不是 AppSecret；小程序源码不得包含 AppSecret、数据库密钥或邮件密钥。
5. 使用近期稳定基础库。安全询单编号使用 `wx.getRandomValues`，不支持的客户端会提示升级微信。
6. 保持“不校验合法域名”关闭。项目设置已启用 `urlCheck`；不能把开发工具跳过校验当作正式网络配置。

## 网络接入

当前唯一服务来源为 `https://sep-hannah-photography-portfolio-qt.vercel.app`，在 `utils/api.js` 与生成的 `utils/catalog.js` 中使用。

真实账号准备好后，在小程序管理后台核对该主体与服务类目的最新准入要求，以及 request / 图片下载域名配置能否接受现有域名。须以后台实际校验与中国大陆微信真机访问结果为准，当前尚未完成这两项验证。若平台不能接受共享 Vercel 域名或网络不稳定，应使用工作室自有合规域名与可达的服务部署；不要关闭域名校验来掩盖问题。

API 与图片地址需同时更新。网站目录执行 `node scripts/sync-mini-catalog.cjs` 会从网站主目录数据重新生成套餐、作品和公开图片地址；发布前运行，避免价格过期。

## 隐私与审核

在真实小程序账号中，按照实际收集字段和第三方服务完成用户隐私保护指引、服务类目及平台要求的主体/备案资料。页面内的隐私说明不能代替微信后台的声明和审核。

本版不读取微信头像、手机号、位置或通讯录；客户自行填写姓名和微信号。没有微信支付、自动订阅消息、微信身份跨设备登录。查询码可找回记录，微信号由 Hannah 人工核对。不得把查询码放到分享链接或日志中。

## 真机验收（发布前必须完成）

- iPhone / Android 分别检查页面、图片加载、长文案、字号与底部按钮。
- 四类场景与四类风格筛选、六张收藏上限、预览、取消收藏，以及带入询单。

- 查询码查进度、从本机移除、重新添加、后台变更状态后刷新；私人页面不可分享。
- 真机验证通过后再上传体验版，添加体验人员；完成微信审核后发布。
