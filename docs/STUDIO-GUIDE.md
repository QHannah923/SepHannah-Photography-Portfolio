# SepHannah 工作室使用说明

## 接单

客户选套餐、风格与日期后提交询单。信息进入后台 `/admin`。这一步不会锁定日期，也不会向客户收款。后台可记录报价、已收定金、私人备注和拍摄时间。状态依次可选 New / Quoted / Confirmed / Editing / Completed / Cancelled。

确认订单前请填写完整占用时间，包含妆造和交通。已确认、修片中和完成的订单会屏蔽重叠公开时段。取消订单会释放时段。系统也会阻止与导入的“工作”日历冲突的新确认。

“Copy a reply”只复制回复草稿，不会替你发送消息。检查价格和档期后再发送。客户可用提交后获得的私人查询码查询进展；查询码不是短订单编号，不要公开分享。

## 发布档期

在后台 Availability 填写起止时间，发布可供询问的窗口。所有后台时间为 Brisbane / AEST（UTC+10）。空白日期表示没有公开时段，不一定代表约满。iCloud 没有事件的时间不会被自动认定为可预约，避免把私人时间误发布。

可用“Open a few weeks at once”一次发布最多31天的固定时段，选择星期与起止时间。重复发布不会覆盖已关闭的窗口。

在 Apple Calendar 选中“工作”，选择文件 → 导出 → 导出，得到 `.ics`。后台选择此文件，预览后导入。只保存忙碌时间及事件的不可逆标识，不保存姓名、标题或备注。

**当前是日历快照，不是持续自动同步。** 修改 iPhone 日历后请重新导入。默认覆盖未来两年；后台显示上次导入时间。2026-09-10 已成功导入 17 个未来忙碌时段。原日历中的夜间时间按原值保留，没有擅自改为白天。

## 邮件

询单先存入数据库，再尝试发到工作室邮箱。邮件失败不会丢失询单，后台会显示需要处理的通知，并支持重试。成功意味着邮件服务接受发送，不能代替实际收件箱检查。上线前必须完成一次真实收件测试。

## 改价格、照片与风格

网站价格统一在 `src/lib/studio.ts`。更新后运行 `node scripts/sync-mini-catalog.cjs` 同步小程序，再分别发布网站和小程序。照片来自现有作品；真实胶片拍摄与数码胶片感调色分开描述。

## 客户隐私

后台只在登录后提供联系方式与私人备注。公开日历仅返回可询问的窗口；客户查询只返回自己的状态、报价和时段，不包含其他客人的联系方式。用户申请改正或删除信息时，由 Hannah 在确认身份后处理。小程序保存本机草稿及查询码，移除本机查询码不会取消订单。
